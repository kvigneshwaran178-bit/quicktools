JSON Structure Reference

A quick guide to valid JSON syntax and data types.

Valid JSON Data Types

  • String — always double-quoted: "hello world"
  • Number — integer or float: 42, 3.14, -7
  • Boolean — lowercase only: true / false
  • Null — lowercase: null
  • Array — ordered list: [1, "two", true]
  • Object — key-value pairs: {"key": "value"}

Example: Formatted JSON

{ "user": { "id": 1, "name": "Jane Doe", "active": true, "scores": [98, 87, 95] } }
Frequently Asked Questions

Common questions about JSON formatting and validation.

What is a JSON Formatter?▼
A JSON Formatter is an online tool that takes raw, compact, or poorly structured JSON and reformats it with proper indentation and line breaks. This makes large API responses or config files much easier to read and debug.
How do I validate JSON online?▼
Paste your JSON text into the Input box and click Validate. The tool will parse it and either confirm it is valid or show you the exact error — including which line and character caused the problem.
What is the difference between Beautify and Minify?▼
Beautify adds indentation and newlines to make JSON human-readable. Minify does the opposite — it removes all unnecessary whitespace to reduce file size, which is useful when transmitting JSON over a network or storing it efficiently.
Is my JSON data safe?▼
Completely. All processing happens locally in your browser using JavaScript. Your JSON data is never sent to any server. We have no backend and no logging of any kind.
Can I upload a .json file?▼
Yes. Click the upload zone above the editor or drag and drop any .json file. Its contents will be loaded into the input area automatically, ready to format or validate.
Why is my JSON invalid?▼
The most common issues are: using single quotes instead of double quotes for strings, leaving a trailing comma after the last item in an array or object, missing or mismatched curly braces / square brackets, or using undefined (which is not a valid JSON value).
