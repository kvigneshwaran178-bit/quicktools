What is URL Encoding?

URL encoding converts characters that aren't allowed in URLs into a safe format using percent-encoding (RFC 3986). Every web developer needs it.

🔒

Percent Encoding

Special characters are replaced with a % sign followed by two hex digits representing the ASCII code, e.g. space becomes %20.

🌐

Safe Transmission

Encoded URLs can travel safely over HTTP without ambiguity. Characters like &, =, ? have special meaning and must be escaped in values.

⚙️

encodeURIComponent

Use this for encoding individual query parameter values. It encodes everything except A-Z a-z 0-9 - _ . ! ~ * ' ( ).

🧩

encodeURI vs Component

encodeURI encodes a full URL and preserves delimiters like / : ? #. encodeURIComponent encodes them too — use it for parameter values.

❓ FAQ

Frequently Asked Questions

What is URL encoding and why do I need it?
+
URL encoding (percent-encoding) converts characters that aren't allowed in URLs — like spaces, ampersands, or non-ASCII characters — into a universally accepted format. Browsers, APIs, and servers all rely on it to correctly parse URLs. Without encoding, a URL with a space or & in a parameter value would break the query string.
When should I encode a URL?
+
Encode URLs when passing special characters in query string parameters, form submissions, OAuth redirects, API calls, or email links. Characters like spaces, &, =, ?, #, and any non-ASCII characters (accents, CJK) must be encoded in parameter values to prevent parsing errors.
What is the difference between encodeURI and encodeURIComponent?
+
encodeURI is designed for full URLs — it encodes unsafe characters but leaves reserved ones like : / ? # @ ! $ & ' ( ) * + , ; = intact since they have structural meaning in a URL. encodeURIComponent encodes those reserved characters too, making it ideal for encoding individual query parameter keys and values.
Is URL encoding the same as Base64 encoding?
+
No. URL encoding uses %XX hex escapes to make URLs safe for transmission, and the encoded string is still readable. Base64 converts arbitrary binary data into a 64-character ASCII string — the result looks nothing like the input. They solve different problems: URL encoding for URL safety, Base64 for binary-to-text encoding.
Can I decode a partially encoded URL?
+
Yes. Our Auto Detect mode recognises encoded sequences (%XX patterns) and decodes them whether or not the entire URL is encoded. It will decode all percent-encoded sequences found in the input, leaving any unencoded characters unchanged.
Does encoding change the meaning of a URL?
+
Encoding and decoding a URL produces the same semantic result — the encoded version is just a safe representation of the same content. However, incorrectly encoding a URL (for example, encoding the / in a path when you shouldn't) can cause the server to receive a different path than intended. That's why choosing between encodeURI and encodeURIComponent matters.
